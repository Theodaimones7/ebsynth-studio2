# EbSynth Studio 2

Запуск готовой сборки: `EbSynthStudio2.exe`.

## Рабочий процесс

1. Нажмите **Новый проект** и выберите папку для проекта.
2. Нажмите **Открыть кадры** либо **Открыть видео**. Видео автоматически
   разбирается на PNG с помощью встроенного FFmpeg.
3. Перетащите PNG/JPG в правую панель **KEYFRAMES**.
4. Перетащите keyframe из панели на нужную миниатюру таймлайна либо прямо в
   окно просмотра.
5. Перемещайте слой мышью. Угловые точки меняют масштаб, верхняя круглая точка
   — поворот. Keyframe вставляется в масштабе 1:1 и прилипает к центру и краям кадра. Удерживайте **Shift**, чтобы отключить магнит. Точные X/Y, масштаб, угол и прозрачность доступны справа.
   Флажок **Выделить спрайт** затемняет исходный кадр только в предпросмотре.
6. На одном кадре можно разместить несколько слоёв и изменить их порядок.
7. Нажмите **Запустить EbSynth**.
8. Нажмите **Сохранить кадры…**, чтобы выбрать папку для готовой последовательности.
9. Нажмите **Сохранить спрайтшит…**, чтобы выбрать PNG-файл и число колонок.

Цветная полоса под таймлайном показывает диапазон влияния keyframe. Каждый кадр
автоматически использует ближайший keyframe; при равном расстоянии выбирается
более ранний.

Проект сохраняется в `project.ebsynth.json`. Исходные кадры и keyframes
копируются внутрь проекта, поэтому всю папку проекта можно переносить.

При выходе программа добавляет проект в меню **Недавние проекты**. Откройте это
меню на верхней панели, чтобы продолжить работу. Команда **Очистить список**
удаляет только историю и сохраняет файлы проектов.

## Горячие клавиши

- `Ctrl+N` — новый проект;
- `Ctrl+O` — открыть проект;
- `Ctrl+S` — сохранить;
- `Ctrl+Z` / `Ctrl+Y` — отменить / повторить изменение композиции;
- `Delete` — удалить выбранный слой.
