# EbSynth Studio — GUI для пакетной стилизации

`launch_gui.bat` запускает графический интерфейс поверх консольного `ebsynth.exe`.
Дополнительные Python-пакеты не нужны.

## Быстрый старт

1. Соберите движок командой `build-win64-cpu_only.bat`. После успешной сборки
   появится `bin\ebsynth.exe`.
2. Дважды щёлкните `launch_gui.bat`.
3. Укажите папку с исходными кадрами, папку с нарисованными ключевыми кадрами и
   папку результата.
4. Нажмите **Проверить проект**, затем **Запустить синтез**.

Имена изображений должны содержать номер кадра. Например:

```text
frames\frame_0001.png
frames\frame_0002.png
frames\frame_0003.png
keys\paint_0001.png
keys\paint_0003.png
```

Префикс имени и количество нулей могут отличаться: GUI использует последнюю
группу цифр. Для каждого keyframe обязательно должен существовать исходный кадр
с тем же номером и тем же разрешением. Все keyframes также должны иметь разрешение
соответствующего исходного кадра.

GUI назначает каждому кадру ближайший по номеру keyframe. Уже готовые изображения
можно пропускать, поэтому прерванную очередь удобно продолжить. Результат сохраняется
как последовательность PNG с именами исходных кадров.

## Параметры

- **Быстро** — меньше итераций для черновой проверки.
- **Стандарт** — исходные параметры EbSynth.
- **Качество** — больше итераций, patch 7 и дополнительный проход 3×3.
- **CPU/CUDA** — CUDA работает только с CUDA-сборкой проекта.
- **Вес guide** отвечает за следование структуре исходного видео.
- **Вес стиля** отвечает за сохранение нарисованной текстуры.
- **Uniformity** препятствует чрезмерному повторению одних и тех же участков стиля.

Сборка видео из готовых PNG намеренно не выполняется автоматически: частоту кадров,
кодек и цветовые параметры лучше выбирать отдельно в монтажной программе или FFmpeg.
